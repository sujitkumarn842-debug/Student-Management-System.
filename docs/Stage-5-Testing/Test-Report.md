# Stage 5 - Testing

## Testing Objective

The objective of testing is to verify that the Student Management System performs all required operations correctly.

## Test Cases

### Test Case 1 - Add Student
Input: Valid student details  
Expected Result: Student is added successfully.

### Test Case 2 - View Students
Input: Select View Students  
Expected Result: Student records are displayed.

### Test Case 3 - Search Student
Input: Existing student ID  
Expected Result: Correct student details are displayed.

### Test Case 4 - Search Invalid Student
Input: Non-existing student ID  
Expected Result: Student not found message is displayed.

### Test Case 5 - Delete Student
Input: Existing student ID  
Expected Result: Student record is deleted.

### Test Case 6 - Exit
Input: Select Exit  
Expected Result: Application terminates successfully.

## Testing Result

All major functions were tested using the console application. The expected results were obtained for the tested operations.

## Conclusion

The testing confirms that the basic Student Management System functions work as expected.
