 
# Stage 1 - Project Introduction

## Project Title
Student Management System

## Introduction
The Student Management System is a C++ based application designed to manage student records in a simple and organized way.

## Objective
The main objective is to develop a system that can add, view, search, update and delete student information.

## Problem Statement
Managing student records manually can be time-consuming and difficult. The proposed system provides a simple computerized solution for maintaining student records.

## Scope
The system will provide basic student record management operations through a console-based interface.

## Expected Outcome
A working C++ application that efficiently manages student information and demonstrates programming, data structures and file handling concepts.

## Technologies
- C++
- Ubuntu Linux
- GNU C++ Compiler
- Git and GitHub
