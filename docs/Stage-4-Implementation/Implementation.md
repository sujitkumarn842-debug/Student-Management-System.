# Stage 4 - Initial Implementation & Prototype

## 1. Implementation Overview

The Student Management System was implemented using C++ on Ubuntu Linux.

## 2. Implemented Features

The prototype provides the following operations:

1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit

## 3. Student Data

Each student record contains:

- Student ID
- Student Name
- Course
- Marks

## 4. File Storage

Student records are stored in a text file named students.txt.

## 5. Prototype

The application provides a console-based menu:

===== STUDENT MANAGEMENT SYSTEM =====
1. Add student
2. View students
3. Search student
4. Delete student
5. Exit

## 6. Development Tools

- C++
- GNU G++ Compiler
- Ubuntu Linux
- Git
- GitHub

## 7. Expected Prototype Result

The prototype should successfully accept student information and perform the selected management operation.
